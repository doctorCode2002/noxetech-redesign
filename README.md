# NoxeTech redesign

A redesign of [noxetech.com](https://noxetech.com), keeping the original site's copy.

- `site/`: the website (Next.js 16, React 19, Tailwind CSS 4, GSAP, Lenis, IBM Plex)
- `REDESIGN-COMPARISON.md`: before/after comparison and changelog
- `docs/`: design direction notes
- `content/`: the original site's content, used as the source for all copy

## Run locally

```bash
cd site
npm install
npm run dev
```

The Start a Project form is front end only for now: submitting is simulated in the browser and nothing is sent.
